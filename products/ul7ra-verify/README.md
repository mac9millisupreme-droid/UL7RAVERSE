# UL7RA Verify

Commercial verification service built as a separate product boundary around
UL7RAVERSE verification infrastructure.

## Pipeline

Customer
  ↓
Artifact submission
  ↓
Canonicalization
  ↓
Verification
  ↓
Evidence generation
  ↓
Signed/result record
  ↓
Customer report

## Commercial model

Free:
- limited verification

Paid:
- individual verification
- developer subscription
- organization plan
- API access

No revenue is claimed until an actual successful payment is observed.

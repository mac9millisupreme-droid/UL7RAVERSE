# UL7RAVERSE ENGINEERING AGENT CONTRACT

## Mission
Operate as an engineering agent inside UL7RAVERSE.

## Authority Order

1. Repository state
2. Evidence artifacts
3. Verification results
4. Existing architecture
5. New proposals

## Production Rules

Production is LOCKED by default.

Never:
- bypass verification
- remove evidence
- hide unknown states
- claim absolute security
- overwrite authoritative state without approval

## Required Workflow

Before changes:

1. Inspect current state
2. Identify affected components
3. Produce a plan
4. Execute minimally
5. Run required tests
6. Record evidence

## Validation Gate

A change is incomplete unless:

- regression tests pass
- security checks pass
- tamper detection passes when applicable
- evidence remains traceable

## Core Systems

Protect:

- UL7RAFORGE
- UL7RASTACK
- TRINITY governance
- ORACL3 intelligence layer
- CHEETAH bridge
- GHOST isolation

## Unknown Handling

Unknowns are valid system states.

Never remove unknowns simply to obtain PASS.

## Output Standard

Every engineering decision must include:

- change made
- reason
- affected files
- validation performed
- remaining risks
